🌙 Politique de confidentialité

نور الإسلام
Dernière mise à jour : 21 septembre 2026

1. Notre engagement

Nour al-Islam est une application 100 % gratuite, open source et respectueuse de votre vie privée. Nous ne collectons, ne vendons, ni ne partageons aucune donnée personnelle.

2. Données collectées

Aucune donnée personnelle n'est collectée. Toutes vos informations (favoris, habitudes, sessions, préférences) sont stockées localement sur votre appareil via SharedPreferences.

2.1 Ce qui est stocké localement

  • ⭐ Vos duas, adhkar et hadiths favoris
  • 📊 Votre progression (habitudes, séries, stats)
  • ⚙️ Vos préférences (thème, langue, notifications)
  • 🚨 L'historique de vos sessions SOS

2.2 Ce qui n'est JAMAIS collecté

  • ❌ Votre nom, email, téléphone
  • ❌ Votre localisation
  • ❌ Vos contacts
  • ❌ Votre historique de navigation
  • ❌ Vos données biométriques
  • ❌ Toute donnée transmise à un serveur

3. Aucun tracking

Nour al-Islam n'utilise aucun outil d'analyse (Google Analytics, Firebase, etc.). Nous ne savons pas combien de personnes utilisent l'app, ni comment.

4. Aucune publicité

L'application est sans publicité. Aucun réseau publicitaire n'est intégré.

5. Aucun serveur

L'application fonctionne 100 % hors ligne (sauf pour le chargement initial de la page web). Aucune donnée n'est envoyée à un serveur externe.

6. Suppression de vos données

Vous pouvez supprimer toutes vos données à tout moment :

  • Ouvrez l'application
  • Allez dans ⚙️ Paramètres
  • Cliquez sur 🗑️ Supprimer toutes mes données
  • Confirmez

La suppression est immédiate et irréversible.

7. Sécurité

Vos données sont stockées localement sur votre appareil. La sécurité dépend donc des protections de votre appareil (code PIN, biométrie, chiffrement).

8. Code source ouvert

Le code source complet est disponible sur GitHub : github.com/momokeith131-boop/nour-al-islam

Vous pouvez vérifier par vous-même que nous ne collectons aucune donnée.

9. Enfants

Nour al-Islam est adaptée à tous les âges. Aucune donnée n'étant collectée, aucune restriction d'âge n'est nécessaire.

10. Modifications

Si cette politique change, la nouvelle version sera publiée sur cette page. La date de mise à jour sera modifiée en conséquence.

11. Contact

Pour toute question : Ouvrir une issue sur GitHub
